# E-commerce Design Procedure

Use this skill for storefront, checkout, tracking, payment, and admin UX.

1. Identify whether the screen serves a customer or an administrator; do not make the storefront look like an admin dashboard.
2. Start with the mobile flow, then expand layout without changing action priority.
3. Give each decision screen one main call to action where practical and keep checkout hierarchy obvious.
4. Show prices, discounts, shipping, totals, stock state, and payment verification state in clear language.
5. Display successful order progress as the five-stage timeline: `CONFIRMED`, `PREPARING`, `SHIPPING`, `ARRIVING`, `DELIVERED`.
6. Separate cancellation, failed payment, return, refund, and other exception states from the successful timeline.
7. Use semantic HTML, visible accessible labels, keyboard operation, visible focus, and touch targets of at least 44px.
8. Never communicate status by color alone; pair color with text, iconography, or shape and maintain readable contrast.
9. Respect reduced-motion preferences and avoid motion that does not clarify feedback or continuity.
10. Avoid excessive glass, neon, decorative effects, and generic AI-generated dashboard aesthetics.
11. Prefer native controls and established project patterns over custom widgets and new UI dependencies.
12. Review loading, empty, error, disabled, success, and narrow-screen states before completion.
